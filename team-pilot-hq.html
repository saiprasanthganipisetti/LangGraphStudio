🚀 FINAL DESTINATION

From requirements to responsibilities

Bring the workshop concepts together in a collaborative AI project-management assistant. Your team can explore the workflow, enter a project brief, define six team profiles, review a sample allocation and prepare assignment emails.

Byte says: “This is our MVP command centre! The sample run is a local interactive simulation. It helps your team make architecture and product decisions; it does not call an LLM, send email or upload files to a server.”

Generate example work packages from the brief and propose owners based on profile skill matches and available capacity. This demo uses transparent keyword scoring, not an LLM or an optimisation solver.

🏗️ Architecture decisions for the real MVP

Frontend

Plain HTML, CSS and JavaScript. Upload UI, profile editor, progress stream, allocation review and email preview.

API

FastAPI. Authenticated endpoints for project intake, graph runs, approval/resume, profiles and email previews.

Orchestration

LangGraph StateGraph with checkpointer, conditional routing, subgraphs and human interrupts.

Persistence

Durable checkpoint backend plus application database / Store for project and team records.

Research tools

Approved web/docs search and internal knowledge retrieval, with source provenance and access controls.

Deployment

AWS deployment target, secrets manager, logging, metrics, secure document storage and SMTP service integration.

💻 Backend starter kit

The V9 ZIP includes a separate teampilot-backend-starter/ folder with starter state, graph, FastAPI routes, email-service abstraction and requirements. It is a scaffold—not a production-ready service. Review the README before running it.

The backend deliberately does not implement real document parsing, authentication, database persistence, LLM provider credentials or SMTP sending. Those require environment-specific decisions and security review.
